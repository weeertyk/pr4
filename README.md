# AI Travel Companion

AI Travel Companion - это MVP интеллектуального помощника для путешественников, который сопровождает пользователя в реальном времени. В отличие от обычных туристических сервисов, приложение не ограничивается списком мест: оно учитывает текущий контекст пользователя, анализирует ситуацию и предлагает следующее полезное действие.

Проект разрабатывается как учебный web MVP и демонстрирует ключевую идею продукта: помочь путешественнику быстрее принимать решения во время поездки с учетом геолокации, времени, бюджета, событий маршрута и факторов безопасности.

## Что умеет MVP

- подбирать следующее релевантное действие для пользователя +-
- показывать ближайшие места на карте +
- перестраивать план дня при изменении ситуации -
- оценивать риск для точки или зоны -
- сохранять предпочтения пользователя через onboarding +-
- работать с маршрутом и навигационным сценарием -

## Основная идея продукта

Система анализирует контекст путешественника:

- геопозицию
- текущее время
- бюджетные предпочтения
- стиль поездки
- состояние плана дня
- события и потенциальные риски

На основе этих данных приложение не просто рекомендует места, а предлагает готовые действия: куда пойти сейчас, как безопаснее двигаться дальше и чем заменить выпавший пункт маршрута.

## Архитектура MVP

В проекте используется `Supabase-first` подход:

- схема данных хранится в SQL-файлах в `supabase/sql/`
- приложение работает с данными через `supabase-js`
- геозапросы выполняются через `Supabase RPC` и SQL-функции
- интерфейс реализован как `Next.js` приложение с набором экранов пользовательского сценария

## Ключевые сценарии

### 1. Best Next Action

Пользователь получает следующую наиболее уместную рекомендацию с учетом текущего контекста и предпочтений.

### 2. Trip Recovery

Если исходный план перестал быть актуальным, приложение предлагает обновленный вариант маршрута или замену точки.

### 3. Safety Scanner

Пользователь может проверить уровень риска для места или района перед следующим действием.

## Локальный запуск

### 1. Установка зависимостей

```bash
pnpm install
```

### 2. Настройка переменных окружения

Создайте файл `.env.local` на основе `.env.example`:

```env
NEXT_PUBLIC_SUPABASE_URL="https://[YOUR-PROJECT-REF].supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="[YOUR-ANON-KEY]"
SUPABASE_SERVICE_ROLE_KEY="[YOUR-SERVICE-ROLE-KEY]"
OPENROUTESERVICE_API_KEY="[YOUR-OPENROUTESERVICE-API-KEY]"
```

Примечания:

- `OPENROUTESERVICE_API_KEY` нужен для построения маршрутов
- без корректно настроенного `Supabase` большая часть сценариев MVP работать не будет

### 3. Подготовка базы данных Supabase

Выполните SQL-файлы по порядку:

1. `supabase/sql/001_extensions.sql`
2. `supabase/sql/002_schema.sql`
3. `supabase/sql/003_geo_functions.sql`
4. `supabase/sql/004_seed.sql`

Это создаст:

- основные таблицы приложения
- `PostGIS`-расширения
- географические RPC-функции
- тестовые данные для демонстрации MVP

### 4. Запуск dev-сервера

```bash
pnpm dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

## Статус проекта

На текущем этапе это рабочий учебный MVP, ориентированный на демонстрацию продуктовой логики, а не на полный production-ready функционал. Репозиторий уже содержит клиентскую часть, API-роуты, SQL-схему, demo-данные и базовую интеграцию карты и маршрутизации.

Дальнейшее развитие проекта может включать:

- улучшение onboarding и settings flow
- полировку карты и навигации
- полную интеграцию авторизации
- очистку оставшихся текстов с проблемами кодировки
- подготовку проекта к демонстрации или деплою на `Vercel`
